## 关键结论（当天实测）

- 无接触时 ESN 完全旁路，指令与纯轨迹一致（丝滑）
- 接触（>12 N）时主动减速 + 让位，位移是被动柔顺的 5~15 倍
- 全程无 reflex，终点误差 2~8 mm
- 已知问题：让位方向与外力方向余弦仅 +0.33（teacher 为 +0.95），疑与训练时观测定义不一致
