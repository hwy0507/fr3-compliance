### 观测与动作语义

| canonical48 索引（从 0 开始） | 含义 | 真机来源 |
|---|---|---|
| 0–6 / 7–13 | q / dq，rad / rad/s | RobotState |
| 14–19 | 名义任务 twist，m/s、rad/s | 本轮 WBC 的 J·qdot，旋转到经核准的训练世界坐标 |
| 20–25 | 目标减实际的位置与旋转向量误差 | EE 位姿与经核准参考 |
| 26–31 | 名义 twist 减实测 twist | J·dq 与名义 twist |
| 32–38 | 原残差算法的关节负载估计，Nm | 独立 NativeObserver；不冒充 SDK 内置估计 |
| 39–44 | EE 点等效环境作用力/矩，N、Nm | 截断 SVD 反解并旋转世界坐标 |
| 45–47 | 路径方向 | 定点为 0；后续移动参考须明确登记 |

ESN 实际使用力/矩和命令、速度误差、位置误差、路径方向构造特征。
输入缩放、裁剪、绝对值通道、144 维交叉特征、64 维储层、状态×上下文读出全部保留。
新回合 reset 一次，接触和释放不 reset，不用故障前状态自动续跑。

动作 a[0] 是反馈权重调节，a[1:4] 为世界坐标线速度残差，a[4:7] 为角速度残差。
原滤波的标度保留为 0.32m/s、0.6rad/s，变化率 1.2m/s²、4rad/s²、scale 4/s；
这不是最终允许真机运动的速度。合成后还受下表的严格包络限制。
原 `twist/direct_esn` 模式的 scale 作用于下一策略区间的反馈，不再次缩放前馈或整体指令。

### 哪些保持，哪些发生了适配

| 部分 | 状态 |
|---|---|
| seed45 权重、ESN 状态更新、原动作滤波 | 逐数值核对保持，未调参 |
| 25 Hz 策略时钟 | 保持；真机首个正周期开始推理，与仿真 t=0 有启动相位差 |
| native_physics40 残差数学公式 | 保持并测试 50µs/1ms；真机 1ms 不等于原 50µs 噪声/延迟表现 |
| 总测量力矩与 FCI 命令 | 明确区分；观测用 tau_J，发送 C + Kv(qdot−dq)，不重复加入重力/摩擦 |
| 内置 K 点力/矩 | 只作独立保护和诊断，沿用已修复的 K→EE 参考点转换；不替代原策略输入 |
| 名义 WBC | **改为保守 resolved-rate WBC**；不是原场景 paper_mpc 的数值复现 |
| 执行层 | 1kHz 力矩伺服 + 更低的包络；不同于仿真执行器及子步率，需另行验证 |
| 仿真碰撞几何、静态柱体约束、阶段/抓放策略 | **未迁移为真实环境约束**，不能据此宣称全臂避障或完成 pick-and-place |
| 保存的零位和示教轨迹 | 本模块没有自动载入、返回、重放；完整轨迹后续单独对齐与核准 |

SDK 的 `Torques` 定义明确要求去除重力/摩擦；`RobotState` 文档给出位姿和力矩字段语义。
来源：[libfranka 0.21.3 control_types.h](https://raw.githubusercontent.com/frankarobotics/libfranka/0.21.3/include/franka/control_types.h)、
[robot_state.h](https://raw.githubusercontent.com/frankarobotics/libfranka/0.21.3/include/franka/robot_state.h)。
数学接口一致性不替代实测方向和传感器校准。

限定范围内的 contact 可继续；collision/reflex/错误仍停止，不抑制厂家保护。
保护失败在核心锁存，SDK 会话抛出并退出；超时目前也按停止异常结束，调用者须保留证据，不能自动清错重试。

会话代码预分配每周期日志，包含完整 RobotState、M/g/被动项、独立残差、两套力估计、

会话退出时保留完整异常对象（包括 SDK ControlException 的尾部日志，若 SDK 有提供），以免只见到故障前最后一帧。
写磁盘和异常格式化必须在离开控制回调后完成；没有实时回调文件 I/O。
`EsnReview` 默认全 false，`ObserverCalibration` 默认未确认且 NaN；仅当证据齐全再填入，禁止为运行而全部改 true/填零。

## 离线检查结果与边界

可复现命令见 `tools/fr3_esn/README.md`。最终小证据存于
`docs/evidence/fr3_esn_port_20261117/`，原始合成夹具和编译日志在本地 artifacts。

- 4,160 帧：包内原始参考观测、长接触/释放、零外力任意上下文、随机输入和幅值饱和；
  C++/原 Python 动作最大差约 1.187e-14，储层约 1.999e-15，滤波约 3.803e-15。
- 2,048 帧：原残差公式在 50µs 和 1ms 两种采样间隔核对，含 SVD 降秩；
  关节负载最大差约 1.027e-15，等效 wrench 约 6.356e-15。
- 核对一次 reset、25Hz 调度、有限接触/释放、接触超时、参考跳变拒绝和有界路径方向输入。
- 故障注入：碰撞/错误、配置不符、操作员停止、超力/超矩/超速、速度区间排除零、
  非有限输入、时间不一致、奇异、测量力矩越界、位移越界；恢复正常样本后仍拒绝继续。
- 校验启动时独立 SDK 残差不能被刚清零的策略观测器隐藏；未确认审阅/校准默认拒绝。
- C++ 数学测试启用 Eigen 禁止堆分配；ASan/UBSan另检，LSan因本机环境限制未启用。
- 测到的离线推理耗时只是本机样本，不是最坏时间上界；SDK 模型计算、完整实时回调、
  CPU 调度、网络延迟及真实噪声下表现均未验收。
- 未做新的物理仿真回合、未训练、未连接机器人，不能给真机成功率、接触稳定性或被动性保证。

## 上机之前仍缺的确认

1. **先闭环此前无接触保护退出**：确定工具负载/质心/TCP依据，检查静止残差随姿态变化、
   传感器/模型状态和有效碰撞阈值来源。不能靠抬高阈值、自动归零或缩小输入掩盖问题。
2. **观测器校准**：测量力矩的方向与模型定义、实际摩擦/被动项、1kHz 差分噪声与延迟，
   EE/TCP 参考点、世界坐标旋转；先采数据离线/影子推理，不能只把 tau_ext 或内置 wrench 填进去。
3. **底层执行器迁移**：当前低速 resolved-rate/力矩伺服与原 paper_mpc 有差异，
   需用记录输入比较、必要的离线闭环验证和获准的定点测试判断能否保留目标柔顺行为。
4. **实时与停止**：实际主机1kHz运行裕量、命令成功率、完整日志落盘、操作员停止链和停止距离。
5. **实验任务**：先定点短时轻推；随后才是小段轨迹参考。原完整示教轨迹超出本候选4cm定点包络，
   不能直接塞进来，也不能为跑完整轨迹随手放宽保护。夹物、相机和抓放动作另行验收。
