# 原生笛卡尔阻抗：定点轻推测试候选

后续同日补充：[受控启动、Ready与停止入口及参数来源核查](FR3_NATIVE_CONTROLLED_START_20261117.md)。新增入口默认禁用真机执行；原刚度与有效碰撞来源仍未核实，未获得运动/真实参数写入授权。本提案下述“无CLI”描述对应最初离线准备版本，现以补充文档说明的新入口为准。

日期：2026-11-17。状态：**代码/建议参数及离线检查准备；未经确认，不启动真机试验。**
本轮未连接机器人、调用真实参数设置、进入控制环、清错或操作夹爪。
此版本独立于原位置重放和 VMC，不修改其保护逻辑或参数。

## 1. 预期行为与实现

使用 Franka 原生 `kCartesianImpedance`，输出固定 `JointPositions` 参考：
厂家根据该关节参考计算目标末端位姿，并由内置笛卡尔阻抗执行。
目标在启动点保持，手动轻推时允许有限偏移，释放后由原生控制器回到参考附近。
没有外置力矩指令、VMC、轨迹播放、自动回零或碰撞阈值写入。

首次参考锁存首个有效回调的 `q_d`，保证首指令连续，之后一直保持，
不把被推开的位置重新设成目标。进入控制前检查 q/q_d、速度/加速度、FK位姿差、
工具配置、已审阅静态基线和零速度可保持条件；检查失败不会写入刚度。

厂家支持运动生成器与原生笛卡尔阻抗组合，刚度按已有 K 坐标系方向生效：
[官方架构说明](https://frankarobotics.github.io/docs/doc/libfranka/docs/overview.html)、
[libfranka 0.21.3 Robot API](https://raw.githubusercontent.com/frankarobotics/libfranka/0.21.3/include/franka/robot.h)。
固定 q 是固定参考，不是要求实际关节始终与指令完全重合；软件检查改用下述有限偏移边界。

## 2. 建议刚度

以下是本项目为首次短时定点检查提出的工程候选，**不是厂家认证的人机接触安全参数**。
当前实现冻结这组六维刚度；更换建议值需重新审阅和检查，不接受随意提高参数。

| K 轴 | 建议值 | 用意 |
|---|---:|---|
| x、y 平移 | 各 300 N/m | 便于低力、短距离横向让位 |
| z 平移 | 800 N/m | 首轮不做竖直推压，较高刚度限制竖向偏移 |
| 绕 x/y/z 转动 | 各 50 Nm/rad | 首轮不主动扭转工具 |

按准静态 `F≈K·x`，横向1/2/3 N分别对应约3.3/6.7/10 mm。
这只是弹簧近似；内置阻尼、有效惯量、模型误差、耦合及实际施力点会改变响应。
本方案不自定义内置阻尼，不宣称已证明稳定性、回位时间或被动性。

K 坐标不是默认等于基座坐标。首次只沿现有 K-x/K-y 平面轻推；
会话检查 K-z 与基座竖直轴的夹角在5°内（允许正反向），否则拒绝该横向方案。
不调用 `setK` 改坐标。相机/支架/线缆不能作为施力部位；实际接触点和力臂需先确认。

## 3. 限速、接触和退出边界

| 类别 | 建议/实现值 |
|---|---|
| 参考平移/转动/关节速度 | **0**，目标固定；首次连续性通过后不移动参考 |
| 实测 TCP 平移速度 | > **5 cm/s** 退出 |
| 实测 TCP 角速度 | > **0.2 rad/s** 退出 |
| 实测任一关节速度 | > **0.15 rad/s**（约8.6°/s）退出，同时查当前方向速度界 |
| 末端总位置偏移 | > **15 mm** 退出 |
| K-z 方向位置偏移 | > **5 mm** 退出 |
| 姿态偏移 | > **3°** 退出 |
| 单关节相对起点偏移 | > **0.17 rad**（约9.7°）退出；距关节限位至少0.17 rad |
| 现场轻推建议 | 仅横向，目标 **1–3 N**，缓慢施力、及时释放；需有量级依据 |
| 相对基线力变化 | > **4 N** 退出；K-z 分量变化 > **1 N** 退出 |
| 原始绝对力范数 | > **6 N** 退出，K点和EE点分别检查 |
| 相对基线力矩变化 | > **0.25 Nm** 退出，K/EE均检查 |
| 原始绝对力矩范数 | > **1.5 Nm** 退出，K/EE均检查 |
| 接触进入/释放 | 相对基线力变化 **1 N / 0.5 N**；普通SDK contact也进入接触 |
| 释放确认 | 低于释放界持续 **0.25 s**，进入回位观察 |
| 接触及回位超时 | 从接触开始到恢复停稳合计 **2 s**；超过即停止 |
| 单次会话 | 最长 **15 s**；到期仍接触/未停稳则保护退出，不强行回零 |
| 开始阶段 | 前 **3 s 不接触**；3 s后偏移≤3mm、角差≤0.01rad、速度低，才标记Ready |
| 回调间隔 | > **2 ms**、时间回退或dt与机器人时间不一致即退出 |
| 通信成功率 | 会话前100ms为统计建立期；随后 < **99%** 即退出，SDK错误始终检查 |
| 外部关节力矩 | 轴1–7界限 `[5,5,5,5,2,2,2] Nm` |
| 实测总关节力矩 | 轴1–7界限 `[60,60,60,60,9,9,9] Nm` |

**实测速率边界是超限停止监测，不是对人手外推速度或原生弹性回位速度的硬保证。**
目标速度为零也不意味着机械臂实际不能动；原生控制器的实际响应需要先做无接触保持验收。
软件异常退出交由SDK取消本次控制，停止轨迹和延迟未做物理验收，不能替代急停。

普通contact可在这些边界内继续；collision/reflex、机器人错误、工具配置变化、NaN、
近奇异、零速度不可保持、操作者取消等均锁定退出。不会降低/关闭厂家碰撞保护，
也不能承诺厂家不会先于软件停止。现有厂家保护如果更严格，试验仍可能提前退出。

## 4. 静态基线的资格与用途

需要在**当前姿态、当前完整工具配置、Idle、空夹爪、无手扶/无接触、线缆松弛**时，
保存至少900帧且跨度≥0.9s的新鲜静止数据（建议完整1秒）。
工具/坐标/姿态必须与测试相符，采样时间严格递增，间隙不超过3ms，
关节速度≤0.005rad/s、关节波动≤0.001rad。

| 基线检查 | 候选值 |
|---|---|
| 原始静止绝对力范数 | ≤2 N，K/EE分别检查 |
| 原始静止绝对力矩范数 | ≤1 Nm，K/EE分别检查 |
| 任一样本相对均值的变化 | 力≤0.2 N、力矩≤0.1 Nm，K/EE分别检查 |
| 基线与新鲜起点匹配 | 关节≤0.001rad、位置≤1mm、姿态≤0.005rad |
| 进入控制瞬间与基线匹配 | K点力变化≤0.2N、力矩变化≤0.1Nm |

基线均值只用于识别新增接触及变化界，不进入控制力矩、不改变参考、不修改机器人估计。
绝对力/力矩始终独立检查，基线不动态更新，持续推力不能被学习成“零力”。
这些是新的原生试验候选门，不是修改旧 VMC 的启动条件。
通过基线门只说明本窗口符合候选，不能代替工具负载和传感器准确性验证。

## 5. 参数写入、恢复与授权

**当前没有执行真实读写或运动。** 为避免下一次测试留下未知刚度，会话要求：

1. 用户确认本候选、实际运动/施力范围，以及本次写入测试刚度和结束后恢复原刚度。
2. 原刚度六维数值必须有可信来源。公开 `RobotState`/Robot API没有阻抗刚度数值getter；
   不能用旧Desk任务、API示例、惯例或合成测试中的数字冒充当前原值。
3. 负载/坐标、静态基线、有效碰撞保护、实时与停止行为、全臂净空/线缆余量和现场监护已审阅。

`Review` 的9个检查位均默认false，原刚度无默认可用值；检查未完成时，
`run_reviewed_native_hold` 在读状态或写参数前拒绝。
预检成功后才写一次候选刚度，执行一段hold，退出控制后尝试恢复已核实的原刚度。
即使第一次setter的应答丢失，也尝试恢复，避免把“收到异常”当作“从未写入”。
恢复失败会保留标记和异常；若同时存在原控制异常，保留原异常动态类型及SDK尾部日志，
恢复错误另存 `restoration_failure`，不会自动清错、重试控制或执行返回动作。
断网/掉电时不能保证恢复成功，必须在后续操作前人工核对参数状态。

审阅清单：[REVIEW_TEMPLATE.json](../tools/fr3_native/REVIEW_TEMPLATE.json)。
它只是待填写清单，没有执行权限，也不是一个可加载即启动的配置。

- [check_offline.py](../tools/fr3_native/check_offline.py)：严格编译、合成状态/假setter验证、
  执行入口拒绝检查、ASan/UBSan与源码hash证据。

静态基线污染、首参考连续且不随推力重锚定、故障锁存和参数恢复的成功/失败组合。
guard测试禁用Eigen堆分配；这不证明SDK模型、原生控制器或完整会话已通过硬件实时性。
断言数量含循环，不能当作独立物理工况数量。未仿造或报告硬件试验成功。
