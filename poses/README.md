## 使用方式

```bash
# 1. 拷到本机姿态目录（程序按名字从 ~/franka-poses 读取）
cp poses/*.json ~/franka-poses/

# 2. 移动前先做运动学校验（只读，不动机械臂）
safe_fk 172.16.0.2 pos3        # 看末端行程、关节差、风险提示

# 3. 位置控制移动（带自动恢复重试）
safe_goto_retry 172.16.0.2 pos3 0.15 5 0.02

# 4. ESN 顺应控制（减速 + 让位）
esn_yield 172.16.0.2 home pos2 0.15 high

# 5. 多段链路
esn_chain.sh 172.16.0.2 home pos2 pos3 pos4 home 0.15
```

## 注意

1. **位姿与具体机械臂绑定**：换机器、重新标定或挪动底座后必须重新示教，直接复用会撞。
2. **pos2 / pos3 的末端 z 接近或低于安装平面**（−0.023 m / +0.051 m），移动路径上要确认没有台面、夹具阻挡。
3. **pos3 的 q2 = +18.5°（后仰）**，从某些姿态过去时大臂会向后扫，后方需留空。
4. 所有姿态的 q4 都在 −110°~−138°，属于正常抓取构型，没有贴限位。
